About Me

I'm a highly motivated aspiring penetration tester with a strong technical foundation in Python, PHP, C++, JavaScript, and Node.js. I focus on web application security, network security, vulnerability assessment, and understanding systems well enough to identify and responsibly exploit security weaknesses.

My practical security training includes hands-on work with OWASP Top 10 vulnerabilities, PortSwigger Web Security Academy, Linux and Windows environments, network enumeration, exploitation, and privilege escalation.

I regularly work with tools such as Nmap, Burp Suite, FFUF, Gobuster, Metasploit, Hydra, NetExec, Impacket, Proxychains, and Chisel. I'm currently progressing through the eJPT v2 path while strengthening my Active Directory, network penetration testing, and cloud security foundations.

I train against deliberately vulnerable environments and focus on building practical skills through labs, CTFs, vulnerability research, and security-focused projects.
