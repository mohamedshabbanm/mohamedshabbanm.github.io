About Me

I'm a highly motivated aspiring penetration tester with a strong technical foundation in PHP, C++, and Python. I focus on web application security — finding logic flaws, chaining vulnerabilities, and understanding systems well enough to break them responsibly.

My practical work is anchored in PortSwigger Web Security Academy, where I've built hands-on experience across SQL injection, XSS, LFI, SSRF, XXE, and command injection. I'm currently working through the eJPT v2 certification, with OSCP+ as my next milestone, following a structured five-phase roadmap covering scanning and enumeration through Active Directory pivoting. Alongside application-layer testing, I'm building foundational AWS and cloud security knowledge — IAM, S3 exposure, network hardening, and logging — since most of what I test now runs on cloud infrastructure.

I train against deliberately vulnerable targets — Metasploitable 2 and VulnHub's Vulnerable AD v2 — and I build the tooling to support that study rather than just consuming courses. I'm open to bug bounty programs, freelance work, and junior penetration testing roles.
